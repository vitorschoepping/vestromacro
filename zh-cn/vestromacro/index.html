  • 智能等待

    把“等待 3 秒”换成“等待窗口出现”、“等待程序加载完成”或“等待屏幕上出现某张图像”。

  • 循环和列表

    可以将部分步骤重复任意次数，支持循环嵌套，每一轮输入列表中的不同值。

  • 用暂存复制和粘贴

    Ctrl+C 会把文本存入一个暂存（例如“证件号”），粘贴时在另一个程序中使用这个值，无需来回切换窗口。

  • Excel 风格的函数

    UPPER、PAD、DIGITS、TODAY……像在电子表格中一样，组合出要粘贴的文本。

  • 你的点击，落在正确的位置

    像平常一样录制鼠标点击：左键、右键和滚轮。Vestro 会记住屏幕上的准确位置，并在那里重复。按钮换了位置？点击新位置就行。

使用方法

三个步骤

  1. 1

    录制

    按你平时的方式做一遍任务。Vestro 会记下每次按键和每次点击。

  2. 2

    调整

    把固定时间换成等待，创建循环，使用列表和函数。所有内容自动保存。

  3. 3

    回放

    点击回放，让 Vestro 按你需要的次数重复。

常见问题

常见问题

免费试用怎么用？

下载并打开 Vestro：30 天全部功能开放，无需注册，无需银行卡。每台电脑只能试用一次。30 天后如果没有许可证，Vestro 会以受限模式继续运行：可以录制、回放和编辑，提供 2 个暂存和 2 个常量。列表、函数和循环需要完整版。激活许可证后一切恢复，包括你已经创建的工作流。

需要联网吗？

开始免费试用以及激活和验证许可证时需要联网。试用和固定许可证可以离线使用最多 5 天。浮动许可证需要联网才能占用席位。

可以更换电脑吗？

可以。在新电脑上输入密钥，申请在这台电脑上使用许可证：由当前电脑批准。之后 90 天内不能再次更换。如果旧电脑已经不在了（已格式化或损坏），请通过邮件联系支持。

Windows 或杀毒软件对文件发出了警告

控制键盘和鼠标的程序有时会被出于谨慎而标记。请只从本网站下载 Vestro。如果出现“Windows 已保护你的电脑”，请点击更多信息，然后点击仍要运行。

宏无法点击以管理员身份打开的程序

Windows 不允许普通程序控制以管理员身份打开的程序。关闭 Vestro，右键点击并选择以管理员身份运行。出现这种情况时，Vestro 自己也会提示。

如何把工作流带到另一台电脑？

在每个工作流中使用导出：会生成一个 .vst 文件，在另一台电脑上导入即可。这个文件也可以用作备份，或发给其他人。

支持 Mac 或 Linux 吗？

不支持。Vestro Macro 适用于 Windows 10 和 11。
