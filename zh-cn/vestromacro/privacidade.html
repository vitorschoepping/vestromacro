隐私

Vestro Macro 使用哪些数据、用途以及保存多久。适用于应用程序和本网站。

只保存在你电脑上的内容

你在 Vestro 中录制和创建的一切：工作流、列表、常量以及宏复制粘贴的内容。这些文件使用 Windows 自带的加密保存，不会发送到任何地方。

应用程序发送的内容

为了激活许可证并不时验证其是否仍然有效，Vestro 会向许可证服务器发送：

  • 许可证密钥；
  • 电脑指纹：根据 Windows ID 和主板型号计算出的代码，无法据此还原这些数据；
  • 电脑名称和 Windows 用户名；
  • 应用程序版本。

服务器还会记录验证请求来源的 IP 地址。

这些数据用于验证许可证、将固定许可证绑定到一台电脑、管理浮动许可证的席位、批准更换电脑以及阻止滥用行为。

免费试用

在没有许可证密钥的情况下打开 Vestro 时，它会向服务器申请 30 天免费试用，并且只发送：

  • 电脑指纹（与上文相同的代码）；
  • 电脑名称；
  • 应用程序版本。

服务器保存这些数据，用来记住这台电脑已经使用过试用（这样重新安装后试用不会重新开始），并知道试用何时结束。试用期间不会发送 Windows 用户名，IP 地址只在当时用于限制滥用，不会被保存。出于同样目的，只会保存一天请求来源网络的代码，无法据此得知 IP。

更新

为了检查是否有新版本，Vestro 只向服务器发送已安装的版本号，不会被保存。新版本从 GitHub 下载，下载文件存放在那里。

网站账户

如果你在网站上创建账户，我们会保存你提供的姓名、邮箱和联系电话，密码只以打乱后的形式（哈希）保存，无法据此得知密码。只有在你打开我们发到你邮箱的链接后，账户才会创建。你可以在账户中查看和修改这些数据。你添加的许可证会与账户绑定，方便你查看其状态。

我们只用你的邮箱发送账户相关链接（确认邮箱、设置新密码），通过邮件发送服务 Resend 投递，它会收到你的地址和邮件内容。每个链接只能使用一次，并会过期（48 小时；新密码链接为 1 小时）。

登录时，网站会在你的浏览器中保存唯一一个 Cookie，用于保持登录状态。它不做任何跟踪，有效期 30 天，或直到你退出登录。出于安全考虑，会话中会保存你登录时的 IP 地址。多次输错密码会暂时锁定几分钟；用于此限制的 IP 不会被保存。发送邮件的请求（注册、“忘记密码”和更改邮箱）也会在一天内按来源网络的代码计数，无法据此得知 IP。

为了用你的语言打开网站，并判断网站购买是否可用，网站会使用访问来源的国家（由 Cloudflare 根据 IP 提供）；如果没有国家信息，则使用浏览器的语言。这些信息不会被保存。

购买时

在网站购买需要账户：许可证创建时即与账户绑定，使用账户的姓名、邮箱和电话。付款在 Mercado Pago 完成，付款信息（Pix、银行卡、CPF）由你直接提供给 Mercado Pago，适用Mercado Pago 隐私政策。Vestro Macro 不会查看或保存银行卡信息：只保存订单（套餐、金额、日期和 Mercado Pago 的付款编号），自动续费时还保存 Mercado Pago 的订阅编号、订阅状态和下次扣款日期。许可证密钥会发送到你的邮箱，并加密保存，方便你在账户中复制。

通过邮件或 WhatsApp 购买时，你提供的姓名和联系方式会与许可证一起保存，用于识别许可证和提供支持。

保存多久

  • 许可证的验证记录会在 180 天后自动删除。
  • 免费试用记录（电脑指纹、电脑名称和日期）会被保存，以免同一台电脑再次获得试用。
  • 通过邮件发送的链接（以及注册时在打开链接前填写的数据）会在你使用链接或链接过期时删除。
  • 账户会话（Cookie 和你登录时的 IP）会在你退出登录、修改密码或邮箱，或 30 天后删除。账户数据在账户存在期间保留。
  • 未付款的订单会在 30 天后删除。已付款的订单会作为销售记录保存（即使删除账户后也会保留，但不再与账户关联）。
  • 许可证数据（姓名、联系方式和最后使用的电脑）在许可证存在期间保留。许可证被删除时，这些数据也会删除。只保留一条删除记录，包含客户姓名和密钥末尾，最多保存 400 天。

数据与谁共享

数据不会被出售或转让。付款在 Mercado Pago 完成（见“购买时”）。许可证服务器和本网站托管在 Cloudflare，该公司只为 Vestro Macro 存储和传输数据，不会用于其他用途，并可能将数据存储在巴西境外，适用Cloudflare 隐私政策。旧版 Vestro 验证许可证时，会先经过 Vestro Macro 自己的服务器，该服务器只把数据转发给 Cloudflare。

本网站不使用分析或跟踪工具，只为登录用户使用账户 Cookie。出于安全考虑，Cloudflare 可能会记录访问者的 IP 地址。下载文件存放在 GitHub，适用GitHub 隐私声明。通过 WhatsApp 的沟通遵循 WhatsApp 自己的政策。

为何可以使用这些数据

验证许可证和网站账户的法律依据是履行合同（巴西《通用数据保护法》LGPD 第 7 条第 V 款）。免费试用和防滥用限制的依据是合法利益：每台电脑只提供一次试用，并保护服务（第 7 条第 IX 款）。

你的权利

你可以要求了解与你有关的数据，并要求更正或删除（包括网站账户）。删除许可证数据会终止许可证：Vestro 仍可运行，但只能使用受限模式。
