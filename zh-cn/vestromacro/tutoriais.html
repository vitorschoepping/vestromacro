学习使用 Vestro

短视频展示 Vestro 在示例电子表格和示例系统中的使用：从第一次点击录制，到把数据从一个程序复制到另一个程序。这些视频也可以在应用顶部的教程按钮中找到。

录制一个任务

录制时，照平常一样完成任务。这里把表格里的一个订单标记为 OK：点击单元格、输入“OK”、按回车。每次点击和每次按键都会变成工作流中的一个方块，每个箭头记录它们之间的时间。

步骤

  1. 打开一个工作流，点击录制（或按 F9）。
  2. Vestro 会隐藏起来，并在屏幕顶部显示录制中标记。
  3. 照常完成任务：这里是点击单元格并输入OK。
  4. 再按一次 F9 停止。
  5. 完成：每次点击和每次按键都变成了一个方块，箭头记录它们之间的时间。

回放

工作流“标记 OK”会输入“OK”并按回车。选中第一个单元格并重复 3 次，Vestro 会连续标记三个订单。默认情况下回放时它会让开，让按键发送到正确的程序。

步骤

  1. 先准备好程序：这里是将要输入文字的第一个单元格。
  2. 在重复中选择次数。速度可以加快或放慢。
  3. 点击回放（或按 F8）。宏运行时 Vestro 会让开，结束后再回来。
  4. 想看到正在运行的方块？在回放选项中关闭最小化，并在程序处于前台时使用 F8。
  5. 要中途停止，按 Esc。∞ 会一直重复，直到你停止。

编辑工作流

录制后，一切都可以直接在流程中调整。这里，“OK”的两个字母合并成一个文本动作，等待有了自己的时间，标记订单的那一段变成了 3 轮的循环。

步骤

  1. 点击一个方块，可在下方面板中查看和修改详情。
  2. 用 Shift + 点击选中多个，按 Delete 删除。
  3. 从面板拖一个动作（这里是文本）到合适的位置，然后输入文字。
  4. 点击一个箭头，修改到下一个动作之前的等待时间。
  5. 选中一段并按 Ctrl+G，把它变成循环。选择轮数。
  6. 回放检查一下。出错了？Ctrl+Z 撤销。

查看鼠标点在哪里

每个黄色方块都是一次鼠标点击，带有它在屏幕上的位置。小眼睛会用一个准星在最上层标出这个点。选中多个方块时，Vestro 会按顺序显示所有带编号的点击。

步骤

  1. 把鼠标移到鼠标方块上，点击小眼睛。
  2. 准星出现在宏将要点击的屏幕位置上。
  3. 选中多个（Ctrl+A 全选）并按 E。
  4. 点击会按发生顺序带编号显示。

修改点击的位置

系统更新后“导出”按钮换了位置：宏开始点在空白处。在这次点击的下方面板中，“在屏幕上点击”会隐藏 Vestro，等你点击新位置。这里还可以更换鼠标按键和点击方式。

步骤

  1. 回放：按钮换了位置，点击落在空白处。
  2. 点击鼠标方块，然后在下方面板中点在屏幕上点击。
  3. Vestro 会隐藏起来：点击按钮的新位置。
  4. 位置会立刻改变。在下方面板中还可以更换鼠标按键和点击方式。
  5. 再回放一次：现在点击正好落在按钮上。

暂存：在程序之间复制粘贴

录制的 Ctrl+C 会变成复制动作，可以把文本存入暂存（M1 到 M5）。粘贴动作使用你选择的暂存，即使中间还有其他复制。在循环中，Vestro 把系统里三位客户的姓名和身份证号搬到表格中。

步骤

  1. 录制的 Ctrl+C 会变成复制动作。在下方面板的把复制的文本存入中，为姓名选择暂存 1。
  2. 对身份证号做同样的操作，放到暂存 2。
  3. 在变量页给暂存命名：客户和身份证号。
  4. 在每个粘贴中，于粘贴什么里选择正确的暂存。
  5. 回放：每一轮 Vestro 复制两个字段，并把两个都粘贴到表格中。

常量：重复使用的文本

常量是不会变的文本：一个邮箱、公司名称、部门代码。在“变量”页写一次，就能在任何粘贴中使用。文本变了？只需在一个地方修改。

步骤

  1. 在变量页写下常量：一个名字和文本。
  2. 在粘贴动作中，于粘贴什么里选择常量。
  3. 选择粘贴（Ctrl+V）或逐字输入。
  4. 回放：常量的文本会填进每一行。
  5. 文本变了？在“变量”页修改：所有用到这个常量的动作都会一起改变。

列表：每一轮一个不同的值

列表保存多个值，每行一个。列表动作输入当前的值，循环每转一轮就换到下一个。这里，客户列表填满了表格的一列。

步骤

  1. 在变量页点击新建列表，每行写一个值。
  2. 在每一轮推进的循环中选择循环：每一轮使用下一个值。
  3. 把列表动作拖进循环里。
  4. 回放：每一轮输入列表中的一位客户。

函数：即时生成文本

函数在粘贴时生成文本。这里用循环的轮次生成订单号：ORD-001、ORD-002、ORD-003。你写公式时结果就会显示出来。

步骤

  1. 在函数页点击新建并起个名字。
  2. 用按钮搭建公式：文本放在引号里，& 连接各部分，LOOP 是第几轮。
  3. 结果立刻显示。保存。
  4. 在粘贴动作中，于粘贴什么里选择函数。
  5. 回放：每一轮函数都会重新计算。
