# Vestro Macro (site publicado): guia para o Claude

Este repositório é **público** e guarda só o site publicado (Cloudflare Pages: as páginas de cada idioma ficam em `pt-br/vestromacro/`, `en/vestromacro/`, `es/vestromacro/` e `zh-cn/vestromacro/`, e as imagens, vídeos, `.css` e `.js` em `vestromacro/`, compartilhados; na raiz ficam `_headers`, `_redirects`, `_routes.json`, `404.html` e `functions/` (leva quem entra sem idioma para o idioma do país e passa a API para o servidor), que valem para o domínio inteiro; a pasta `docs/` é o endereço antigo do GitHub Pages, que só leva para o novo) e os Releases com o `VestroMacro.exe`. Não ponha aqui nada interno: segredo, endereço de servidor, plano de negócio.

- **Não edite o site aqui.** A fonte é a pasta `site/` do repositório privado `vitorschoepping/vestro-macro`; para publicar, rode lá `python tools/publicar_site.py <pasta deste repositório>`.
- **Antes de qualquer trabalho, leia o cérebro do projeto:** `/mnt/project-files/cerebro/INDEX.md` (nas threads do projeto) ou `docs/cerebro/INDEX.md` do `vestro-macro`. Abra só o documento da frente que precisa (o do site é `site.md`).
- Responda em português do Brasil, curto e objetivo.
