Privacidade

Quais dados o Vestro Macro usa, para quê e por quanto tempo. Vale para o aplicativo e para este site.

O que fica só no seu computador

Tudo o que você grava e monta no Vestro: os workflows, as listas, as constantes e o que a macro copia e cola. Esses arquivos ficam guardados com a criptografia do próprio Windows e não são enviados para lugar nenhum.

O que o aplicativo envia

Para ativar a licença e conferir de tempos em tempos se ela continua válida, o Vestro envia ao servidor da licença:

  • a chave de licença;
  • uma impressão do computador: um código calculado a partir do ID do Windows e do modelo da placa-mãe, que não permite recuperar esses dados;
  • o nome do computador e o nome do usuário do Windows;
  • a versão do aplicativo.

O servidor também registra o endereço IP de onde veio a conferência.

Esses dados servem para conferir a licença, prender a licença fixa a um computador, controlar as vagas da flutuante, aprovar a troca de computador e barrar tentativas de abuso.

O teste grátis

Ao abrir o Vestro sem chave de licença, ele pede ao servidor o teste grátis de 30 dias e envia só:

  • a impressão do computador (o mesmo código de cima);
  • o nome do computador;
  • a versão do aplicativo.

O servidor guarda esses dados para lembrar que aquele computador já usou o teste (assim ele não recomeça ao reinstalar) e para saber quando o teste termina. No teste, o nome do usuário do Windows não é enviado, e o endereço IP é usado só na hora, para limitar abusos, sem ser guardado.

Atualizações

Para saber se existe versão nova, o Vestro envia ao servidor só a versão instalada. Nada disso é guardado. A versão nova é baixada do GitHub, onde fica o arquivo de download.

A conta no site

Se você criar uma conta no site, guardamos o nome, o e-mail e o telefone de contato que você informar, e a senha só de um jeito embaralhado (um hash), que não permite descobrir a senha. A conta só é criada depois que você abre o link que mandamos para o seu e-mail. Você vê e muda esses dados na própria conta. As licenças que você adiciona ficam ligadas à conta, para você ver a situação delas.

Usamos o e-mail só para mandar os links da conta (confirmar o e-mail, criar uma senha nova), pelo serviço de envio de e-mails Resend, que recebe o seu endereço e o texto da mensagem para entregar. Cada link funciona uma vez e vence (em 48 horas; o de senha nova, em 1 hora).

Ao entrar, o site guarda no seu navegador um único cookie, necessário para manter você na conta. Ele não rastreia nada e vale por 30 dias, ou até você sair. Junto da sessão fica o endereço IP de onde você entrou, por segurança. Errar a senha muitas vezes trava as tentativas por alguns minutos; o IP usado nesse limite não é guardado.

Para saber se a compra pelo site está disponível, o site usa o país de onde vem o acesso (informado pela Cloudflare a partir do IP), sem guardar.

Quando você compra

O nome e o contato que você passa pelo WhatsApp ficam guardados junto da licença, para identificar a licença e dar suporte.

Por quanto tempo

  • O histórico de conferências da licença é apagado sozinho depois de 180 dias.
  • O registro do teste grátis (impressão do computador, nome do computador e datas) fica guardado para o mesmo computador não ganhar outro teste.
  • Os links mandados por e-mail (e, no cadastro, os dados que você digitou até abrir o link) são apagados quando você usa o link ou quando ele vence.
  • A sessão da conta (o cookie e o IP de onde você entrou) é apagada ao sair, ao trocar a senha ou o e-mail, ou depois de 30 dias. Os dados da conta ficam enquanto ela existir.
  • Os dados da licença (nome, contato e o último computador que usou) ficam enquanto a licença existir. Quando a licença é excluída, eles são apagados. Fica só o registro de que ela foi excluída, com o nome do cliente e o final da chave, por até 400 dias.

Com quem os dados são compartilhados

Os dados não são vendidos nem repassados. O servidor da licença e este site ficam na Cloudflare, empresa que só guarda e entrega os dados para o Vestro Macro, sem usá-los para outro fim, e que pode guardá-los fora do Brasil, conforme a política de privacidade da Cloudflare. As versões mais antigas do Vestro conferem a licença passando antes por um servidor próprio do Vestro Macro, que só repassa os dados para a Cloudflare.

Este site não usa analytics nem rastreamento, e só usa o cookie da conta, para quem entra nela. A Cloudflare pode registrar o endereço IP de quem acessa, por segurança. O arquivo de download fica no GitHub, conforme a declaração de privacidade do GitHub. A conversa pelo WhatsApp segue a política do próprio WhatsApp.

Por que esses dados podem ser usados

Para conferir a licença e para a conta no site, a base é a execução do contrato (Lei Geral de Proteção de Dados, art. 7º, V). Para o teste grátis e para os limites contra abuso, é o interesse legítimo de oferecer o teste uma vez por computador e de proteger o serviço (art. 7º, IX).

Seus direitos

Você pode pedir para saber quais dados existem sobre você, corrigir ou apagar (inclusive a conta do site). Apagar os dados da licença encerra a licença: o Vestro continua funcionando, mas só no modo restrito.
