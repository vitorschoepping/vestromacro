  • Smart waits

    Swap “wait 3 seconds” for “wait for the window to appear”, “the program to finish loading” or “an image to show up on screen”.

  • Loops and lists

    Repeat parts as many times as you want, with loops inside loops, and type a different value from a list on each round.

    Ctrl+C saves the text in a memory, like “ID”, and Paste uses that value in another program, without switching windows back and forth.

  • Your clicks, in the right place

    Record mouse clicks the way you already do: left, right and scroll. Vestro saves the exact spot on the screen and repeats it there. Did a button move? Click the new spot and you're done.

FAQ

Frequently asked questions

How does the free trial work?

Download and open Vestro: you get 30 days with everything unlocked, no sign-up and no card. One trial per computer. After the 30 days, without a license, Vestro keeps working in restricted mode: it records, plays and edits, with 2 memories and 2 constants. Lists, functions and loops are for the full version. Activate a license and everything comes back, including the workflows you've already built.

Do I need internet?

To start the free trial and to activate and check the license, yes. The trial and the fixed license keep working for up to 5 days offline. The floating license needs a connection to hold the seat.

Can I switch computers?

Yes. On the new computer, enter the key and ask to use the license there: the current computer approves it. After that, it can't move again for 90 days. If the old computer no longer exists (formatted, broken), contact support by email.

Windows or my antivirus warned me about the file

Programs that control the keyboard and mouse are sometimes flagged as a precaution. Only download Vestro from this site. If you see “Windows protected your PC”, click More info and then Run anyway.

The macro doesn't click in a program opened as administrator

Windows doesn't let a regular program control another one that's open as administrator. Close Vestro and open it with a right-click, choosing Run as administrator. Vestro itself tells you when this happens.

How do I take my workflows to another computer?

In each workflow, use Export: you get a .json file to import on the other PC. The same file works as a backup and for sending the workflow to someone else.

Does it work on Mac or Linux?

No. Vestro Macro is for Windows 10 and 11.
